# Use Insights

The **Insights** page shows charts of your spending. You can filter every chart by date, workspace, and currency, then open the expenses behind any chart in **Spend**.

---

## Who can use Insights

Insights are available to all members on all plans. Each chart only includes expenses you have permission to see, and some charts have extra requirements. [Learn more about who can see each Insights chart](/articles/new-expensify/insights/How-to-Use-Insights-in-Expensify#who-can-see-insights).

---

## Where to find Insights

In the navigation tabs (on the left on web, on the bottom on mobile), select **Insights**. It sits between **Spend** and **Workspaces**.

You can also open Insights from **Search**. Select **Search** (the magnifying glass icon), type **Insights**, and select the result.

---

## How to filter Insights by date, workspace, and currency

The filters at the top of the Insights page apply to every chart on the page.

1. In the navigation tabs (on the left on web, on the bottom on mobile), select **Insights**.
2. Select **Date** and choose **This month**, **Last month**, **Year to date**, **Last 12 months**, **Custom day**, or **Custom range**.
3. Select **Workspace** and choose the workspaces to include.
4. Select **Group currency** and choose the currency to show amounts in.

The charts update when you change a filter. By default, **Date** is set to **Year to date** and **Group currency** uses your workspace's currency.

The **Workspace** filter only appears if you belong to more than one workspace.

Insights remembers your filter selections, so the page opens with the same filters next time, even on another device.

---

## How to open the expenses behind an Insights chart in Spend

You can open the expenses behind a whole chart or behind a single data point.

To open all expenses behind a chart:

1. Select the three dots **(⋮)** on the chart.
2. Select **View on Spend**.

**Spend** opens in table view with the same filters and grouping as the chart. It shows every result, not only the top 5.

To open the expenses behind one data point, select a point on the line, a bar, or a slice of the donut chart. **Spend** opens a list of the matching expenses, such as the expenses for that merchant, category, member, or time period, with the newest first.

# FAQ

## Why don't the numbers on Insights match Spend?

Insights shows the top 5 results in each ranking chart and converts all amounts to the selected **Group currency**. Spend shows every matching expense. Select **View on Spend** to see the full results behind a chart.

## Why is my Insights page empty?

Charts appear as soon as you have expenses to show.

- If you don't have any expenses yet, the page shows **See where your money goes**. Create an expense to start seeing charts.
- If the page shows **Nothing to show**, no expenses match your filters. Try a longer **Date** range or include more workspaces.
- If a chart shows **Chart unavailable**, there isn't enough data for that chart yet.

## Why can't I see a chart on the Insights page?

Some charts have extra requirements. **Top spenders** appears only if you're a Workspace Admin, Auditor, or approver on a workspace with at least two members. **Top categories** appears only if a workspace you can see has categories enabled.

## Where did the Insights on the Spend page go?

They moved to the **Insights** page. The same spend charts are available there.
