# Upcoming Features: AI & Automation (New Expensify)

This page is an **AgentZero reference** for AI and automation features that are planned or in development for New Expensify. Use it to answer "is this coming soon?" questions accurately. These items are subject to change.

- **Custom Agents & Agent Rules – General Release** – Graduate Custom Agents and Agent Rules from beta to general availability. Agents are already available to all members, but remain labeled as Beta.
- **AI-powered Insights – gated rollout** – Expand access to AI-generated insight cards and contextual Explain answers from Concierge for Insights charts. The existing Insights page does not mean these AI additions are available to everyone. [AI Insights cards implementation](https://github.com/Expensify/App/pull/104564) and [Explain answer development](https://github.com/Expensify/App/pull/106538).
- **AI-assisted rule creation – planned** – Let an admin describe one supported rule in natural language, then review and confirm the structured rule before saving. AI drafts the configuration; it does not replace deterministic enforcement or save rules without confirmation. [AI-assisted rule creation development tracking](https://github.com/Expensify/App/issues/92743).
