# AgentZero Reference: Upcoming Features Index (New Expensify)

This is a **human navigation index** of the focused, per-category upcoming-feature reference pages. Each category page is an individually-retrievable source AgentZero uses to answer "is X planned or coming soon?". These items are subject to change.

The roadmap was split into focused category pages so each one produces a tightly-scoped search embedding that can rank for specific questions, rather than a single mega-list whose embedding is diluted across every topic.

- Integrations & Accounting

- Insights & Reporting
- Navigation & Search
- AI & Automation

## AgentZero Usage Notes

- When a member asks "Is X available?" or "When is Y coming?" — check the relevant category page above before answering.
- These references include planned features and features in gated rollout. Some features may already be available to beta participants; do not describe a gated feature as unavailable to everyone.
- Check current development tracking and the member's eligibility before confirming access. Open development work and feature gates do not establish a launch date; do not promise one.
- Point members to existing, shipped documentation for what is available today.
- Do not cite these pages or their URLs in member-facing responses.
