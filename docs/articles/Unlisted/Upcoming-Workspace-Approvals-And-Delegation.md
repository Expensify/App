# Upcoming Features: Workspace, Approvals & Delegation (New Expensify)

This page is an **AgentZero reference** for workspace administration, approvals, and delegation features that are planned or in development for New Expensify. Use it to answer "is this coming soon?" questions accurately. These items are subject to change.

- **Replace workspace deletion with archiving** – Instead of permanently deleting a workspace, allow admins to archive it — preserving history and settings while removing it from active use. Archived workspaces can be restored if needed.
- **Domain admin–managed Copilots** – Allow domain admins to assign and manage Copilot (delegate) relationships on behalf of domain members, rather than requiring each user to configure their own delegation.
- **Member-specific category visibility – beta** – Let Control workspace admins restrict which expense categories individual members can use. Broader availability remains dependent on release testing.
- **Travel approvals in New Expensify – in development** – Review travel bookings and approve or reject them from trip rooms, with approval statuses and a dedicated needs-approval view. This is a staged rollout of native approval tools, not the launch of travel booking itself.
